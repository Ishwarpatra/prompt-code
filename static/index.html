Turn a rough idea into a prompt that works

Paste what you want to build. Prompt Code picks the right prompt type and writes it, using open-weight models.

How it works

Three steps.

  1. Paste your idea

    Write it the way you would say it. No special format.

  2. Get a recommendation

    Prompt Code works out what you are doing, suggests the prompt type that fits, and says why.

  3. Copy or refine

    Use the prompt as it is. With an account you can ask for changes and keep a history.

The right prompt for each job

Different tasks need different prompts. Pick one to see when it fits.

    Examples

    A rough idea in, a structured prompt out.

    Illustrative example

    Help me design the classes for an inventory app.

    Recommended: role prompt

    You are a senior software architect.
Task: design the classes for an inventory app.
Return: class list, attributes, relationships, open questions.
Ask before assuming anything unclear.
    Illustrative example

    Check how we handle user data.

    Recommended: step-by-step checklist

    Go through each place user data is collected, stored or shared.
For each, state: what, where, who can see it, and the risk.
End with the three biggest risks, ranked.
    Illustrative example

    A helper bot for my shop's customers.

    Recommended: system prompt

    You are a friendly support assistant for a small online shop.
Rules: answer only about orders, delivery and returns. Be brief and polite.
If you are not sure, say so and offer to pass the question to a person.

    Built to keep working

    Models can be busy. Prompt Code plans for that.

    Backups take over

    The plan: if one open-weight model is busy or down, the next one in the list answers.

    You see who answered

    Every result names the model that wrote it, and says when a backup was used.

    Your key stays yours

    The plan: a key you bring is used for your request only. The server is not meant to store it.

    Questions

    Is it free?

    The free try needs no account. It is limited so that free model capacity is shared fairly.

    Do you keep my prompts?

    Free tries are not meant to be saved. With an account, your history is saved so you can reuse it, and you can delete any item or all of it.

    What if a model is down?

    The next model in the list is meant to answer, and the result says which one. If every model is busy, your idea stays in the box so you can try again.

    Can I use my own model key?

    Yes, with an account. The key is meant to be used for your request only and not stored by the server.

    Why no password?

    You sign in with a one-time link sent to your email. There is no password to forget or leak.
