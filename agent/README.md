# agent/

> AGENT-ONLY. Not part of the Prompt Code app.

Entry point for coding agents and maintainers.

1. `docs/STATUS.md`: what is done and not done.
2. `docs/HANDOVER.md`: how to take over.
3. `docs/CODEMAP.md`: which file to open for a problem.
4. `docs/INDEX.md`: which document answers a question.
5. `skills/`: working rules. Start with `skills/agents.md` and `skills/least-assumptions.md`.
6. `reference/`: design mockup, comparison only.

Never import, bundle or ship anything from this folder with the app.
